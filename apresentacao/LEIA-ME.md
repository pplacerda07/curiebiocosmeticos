# Apresentação: mercado, preço e plataforma

14 slides em 16:9 (13,33 x 7,5 polegadas), horizontal.

- `escola-curie-apresentacao.pdf` é o arquivo pronto para apresentar.
- `deck.html` é a fonte. Editar o texto ali e gerar o PDF de novo.

## Gerar o PDF depois de editar

```bash
"C:/Program Files (x86)/Microsoft/Edge/Application/msedge.exe" --headless=new --disable-gpu --no-pdf-header-footer --print-to-pdf="escola-curie-apresentacao.pdf" "file:///CAMINHO/COMPLETO/deck.html"
```

Trocar CAMINHO/COMPLETO pelo caminho desta pasta. O Chrome funciona igual, é só
trocar o executável.

## Regras de escrita

Sem travessão em nenhuma copy, igual ao site e ao curso. Onde o travessão
separava ideias, usar vírgula, ponto ou dois pontos.
